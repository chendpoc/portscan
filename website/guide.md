# 使用指南

PortMaster 是一个 macOS 原生菜单级工具：查看这台 Mac 上正在运行的进程、它们的 CPU / 内存占用，以及每个进程持有的网络端口。采集全部发生在本机（Darwin `libproc` 与本机套接字扫描），不连接任何远程主机。

## 系统要求

- macOS 14 或更高
- Xcode 15 或更高（从源码构建时需要）

## 从源码构建

```bash
git clone https://github.com/chendpoc/portscan.git
cd portscan
xcodebuild -project macos/PortMaster.xcodeproj -scheme PortMaster -configuration Debug build test
```

或者在 Xcode 中打开 `macos/PortMaster.xcodeproj`，选择 **PortMaster** scheme 运行；正式版本用 **Product → Archive**。分发不走 Mac App Store。

::: tip 为什么不启用 App Sandbox？
读取其他进程的信息（命令行、工作目录、套接字归属）在沙箱内无法完成，因此应用未启用 App Sandbox。相应的，它也不索取任何网络权限。
:::

## 两个视图

### Processes · 进程视图

- 当前用户可见的**全部进程**，没有端口的进程也在列表里。
- 列：进程名、PID、CPU、RSS（常驻内存）、端口、项目 / 工作目录。
- 默认按 CPU 降序；点列头可切换排序，实时刷新不会打乱你选的排序。
- CPU 首次采样期间显示「采样中」而不是虚构的 `0.0%`；多核机器上超过 100% 是正常值。
- 点任意一行打开进程检查器：完整启动命令、可执行文件路径、工作目录、父进程链、启动时间、它持有的套接字。

### Ports · 端口视图

- 本机所有监听 / 已绑定的套接字：端口、进程、PID、协议与状态、地址、项目目录。
- 支持直接按端口号搜索——输入 `8787` 直达占用者。
- 同一端口的 IPv4 / IPv6、TCP / UDP 多个监听分行显示，不做合并。

### 刷新控制

- 默认每 2 秒刷新，可选 1 / 2 / 5 秒，支持暂停与手动刷新。
- 进程与套接字**分开采集、分开刷新**：一侧失败时另一侧不受影响，失败的一侧保留上次成功数据并标记过期。

## 数据读数说明

| 你看到的 | 它的含义 |
| --- | --- |
| `CPU` | 该进程最近一段时间内的 CPU 占用率，不是开机以来的平均值 |
| `RSS` | 归属于该进程的常驻内存，以紧凑单位显示 |
| `采样中…` | 进程刚出现或刚重启，尚未积累足够的采样间隔 |
| `Unavailable from macOS` | 系统未授权或无法提供该字段（如其他用户进程的工作目录） |
| `已过期` + 时间戳 | 最近一次采集失败，展示的是上一份成功数据 |
| `—` | 该项确实为零或不存在（如无套接字），与「不可用」严格区分 |

## 它不会做什么

PortMaster 刻意不提供以下能力：

- 终止、重启或以任何方式控制进程
- 历史曲线、性能图表、导出报表
- 网络吞吐量统计、磁盘 I/O 统计
- 多主机监控、远程采集
- 持久化或上传任何命令行、路径、进程历史

## 隐私

所有数据都在本机内存中采集与展示。命令行可能包含令牌、路径等敏感信息，因此只在你点开详情时展示，复制是你的显式操作，应用不写日志、不留历史、不发起任何网络请求。
